Kestrel Relay is a three.js tactical FPS: a 5v5 round-based shooter on an original desert relay-station map, with two spike sites, an economy and buy menu, headshots, recoil and spread, bot teammates and opponents, and synthesized WebAudio sound. No audio files, no build step, just static files served over HTTP.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 to play. First to five rounds takes the match.
